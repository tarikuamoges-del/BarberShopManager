# Barber Shop Manager – Android MVP

A simple offline-first starter app for a 2–3 chair barber shop.

Included:
- Dashboard
- Customer/service recording
- Haircut, beard, wash and combined services
- Price and barber entry
- Daily sales total
- Service count
- Employee list starter
- Transaction report

This is an MVP, not yet connected to a database, payment system, CCTV or AI.
Open in Android Studio and build an APK.

Recommended next version:
1. SQLite/Room database
2. Login/admin roles
3. 2–3 chair/barber scheduling
4. Inventory and product sales
5. Expense/profit tracking
6. Cloud backup
7. Camera/AI integration for service recognition
